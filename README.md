
מערכת לדיירי מעונות סטודנטים, המאפשרת לפרסם ולחפש פריטים למכירה או למסירה.

**יכולות המערכת**

- הרשמה והתחברות באמצעות שם משתמש וסיסמה.
- פרסום פריט למכירה במחיר לבחירת המפרסם, או למסירה ללא עלות.
- עיון בפריטים שפורסמו.
- סינון לפי טווח מחירים, כולל הצגת פריטים למסירה בלבד.
- פנייה לבעל הפריט לצורך תיאום הקנייה או האיסוף

**ישויות**
- משתמש : מזהה יחודי, סיסמה שמורה בצורה מאובטחת, פרטי התקשרות
- פריט: מזהה יחודי, מחיר, תיאור, כותרת, סטטוס זמין/לא זמין

**כללים**
- רק המפרסם יכול לערוך את מחיר המוצר, כותרת+תיאור, סטטוס זמינות
- מחיר לא יכול להיות שלילי
- מחיר 0 = מוצר למסירה
- פריט חייב לכלול כותרת ומחיר
- החיפוש מציג כברירת מחדל רק פריטים זמינים
