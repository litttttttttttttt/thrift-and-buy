
מערכת לדיירי מעונות סטודנטים, המאפשרת לפרסם ולחפש פריטים למכירה או למסירה.

**יכולות המערכת**

- הרשמה והתחברות באמצעות שם משתמש וסיסמה.
- פרסום פריט למכירה במחיר לבחירת המפרסם, או למסירה ללא עלות.
- עיון בפריטים שפורסמו.
- סינון לפי טווח מחירים, כולל הצגת פריטים למסירה בלבד.
- פנייה לבעל הפריט לצורך תיאום הקנייה או האיסוף.
